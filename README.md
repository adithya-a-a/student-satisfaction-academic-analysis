# **Student Satisfaction & Academic Performance Analysis**

## 📌 **Project Overview**

This project focuses on analyzing student academic performance, satisfaction levels, study habits, attendance, and Artificial Intelligence (AI) tool usage using **Python, SQL, and Exploratory Data Analysis (EDA)**.

The objective is to identify patterns and relationships between academic performance, learning behavior, student satisfaction, and AI adoption. Through data cleaning, statistical analysis, SQL queries, and data visualization, the project aims to uncover meaningful insights and provide data-driven recommendations for improving student learning experiences.

## 🎯 **Objectives**

- **Academic Performance:** Analyze CGPA, attendance, and daily study hours.
- **Attendance Analysis:** Explore relationships between attendance, study habits, and academic performance.
- **Student Satisfaction:** Evaluate teaching quality, course content, faculty support, learning resources, infrastructure, and placement support.
- **AI Tool Usage:** Investigate AI adoption patterns and perceptions of AI-assisted learning.
- **Academic Challenges:** Identify common challenges and areas for improvement.
- **SQL Analysis:** Perform data aggregation, filtering, and comparative analysis.
- **Data Visualization:** Present meaningful findings and recommendations.

## 🛠️ **Tools & Technologies**

- **Python** – Data analysis
- **Pandas & NumPy** – Data manipulation and numerical analysis
- **Matplotlib & Seaborn** – Data visualization
- **SQL** – Data querying and analysis
- **Jupyter Notebook** – Interactive analysis
- **GitHub** – Project documentation and portfolio

## 📊 **Key Areas of Analysis**

- **Student Demographics:** Department-wise student analysis
- **Academic Performance:** Attendance and CGPA relationships
- **Study Habits:** Study hours and academic performance
- **Student Satisfaction:** Satisfaction across different factors
- **AI Adoption:** AI tool usage frequency and learning perceptions
- **Academic Challenges:** Common problems and improvement suggestions

## 🔍 **Project Methodology**

**Data Understanding → Data Cleaning → Exploratory Data Analysis → SQL Analysis → Visualization → Insights & Recommendations**

## 📁 **Dataset**

The dataset includes student information, academic performance metrics, satisfaction ratings, learning habits, AI usage patterns, and student feedback.

**Note:** The current practice dataset is synthetic and is used for educational and portfolio demonstration purposes. Findings should not be interpreted as results from a real student survey.
